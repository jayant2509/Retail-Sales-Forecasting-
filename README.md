✅ Scope of Work
1️⃣ Python: Data Cleaning & Visualization
Notebook: Data_cleaning_and_visualization_in_python.ipynb

Tasks:

Loaded raw CSV with Pandas

Cleaned missing values & duplicates

Feature engineering: Year, Month, Region, Category

Created plots with Matplotlib & Seaborn:

Distribution_of_shipping_Days.png

Region_sales.png

monthly_sales.png

Final cleaned data saved as sales_cleaned.csv.

2️⃣ SQL Storage & Queries
Notebook: store_data_SQLite.ipynb

Database: Sales.db

Stored cleaned sales data in SQLite.

Wrote SQL queries for:

Window Functions (moving averages)

CTEs

Joins (Orders, Customers, Products)

KPIs: Top 10 products, month-on-month growth

3️⃣ Dashboard & Forecasting
Tool: Tableau

Files:

book1.twbx — Tableau workbook

book1.pdf — Exported dashboard PDF

Dashboards include:

📈 Sales trends over time

🌍 Region-wise sales breakdown

📊 Product category insights

🔮 Basic forecasting using Tableau analytics
